# Bank-Management-System-Java
#overview
A console-based Bank Management System developed in Java using Object-Oriented Programming concepts such as Abstraction, Inheritance, Encapsulation, and Polymorphism.
## Features
- Add Customer
- Create Savings Account
- Create Current Account
- Deposit Money
- Withdraw Money
- Search Customer
- Search Account
- Display Customer Details
- Display Account Details

## OOP Concepts Used
- Classes & Objects
- Constructors
- Encapsulation
- Inheritance
- Abstraction
- Method Overriding
- Runtime Polymorphism
- Abstract Classes

## Technologies
- Java
- VS Code
